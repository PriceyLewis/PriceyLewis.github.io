Built on the service desk

ReplyKit: the tool I wanted on every shift.

On the service desk I was typing the same ticket updates, unlock confirmations and escalation notes all day. So I built ServiceDesk Toolkit, a Chrome extension that turns a short shortcut into the full reply inside any web-based ticketing system, inbox or chat tool — then grew it into ReplyKit, a product for any team that sends the same messages every day.

  • Type ;unlock, send the whole reply. Fill-in fields ask for the name and ticket number as it expands.
  • Private by design. Replies never leave the computer; password fields are ignored.
  • A real product. Manifest V3, Free/Pro/Team plans, seat-based licence keys and a public website.
  • Tested in a real browser. Playwright loads the extension and types into live text boxes, and runs the licence flow against a fake payment server.
