# Lewis Price — GitHub Pages Portfolio

A zero-cost static portfolio designed for GitHub Pages.

## Publish for free

The cleanest URL is:

`https://priceylewis.github.io`

To get that URL:

1. On GitHub, create a **public** repository named exactly `priceylewis.github.io`.
2. Upload the contents of this folder to the repository root (not the containing folder itself).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.

GitHub will publish the site automatically.

## Files

- `index.html` — portfolio homepage
- `styles.css` — all responsive styling
- `script.js` — tiny progressive enhancement script
- `projects/` — individual project case studies
- `404.html` — fallback page
- `.nojekyll` — tells GitHub Pages to serve the static files directly

## Before publishing

Optional improvements:

- Add your LinkedIn URL when you want it public.
- Add a downloadable CV PDF once you are happy for it to be public.
- Replace the stylised project previews with real screenshots later.
- Add an email/contact link only if you want that address publicly visible.

No npm install, backend, database, paid hosting, or custom domain is required.
