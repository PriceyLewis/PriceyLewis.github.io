Flagship case study · Full-stack web application

PredictMyGrade

A Django academic analytics portfolio application designed to demonstrate end-to-end product engineering: persisted student data, forecasting-style tools, study planning, demo-safe feature gating, settings and recovery flows, and browser-level verification.

The challenge

Academic tools often stop at simple grade calculators. I wanted to explore a broader product where a student could record performance, understand progress, test possible outcomes, organise study activity and move through realistic account and premium-style journeys without the interface feeling like unrelated features stitched together.

The core engineering challenge was product cohesion: keeping data, navigation, calculations, settings, recovery behaviour and feature gating consistent as the application grew.

What I built

  • Persistent university, college and GCSE-oriented tracking flows with weighted progress summaries.
  • Dashboards, targets, what-if forecasting, goals, deadlines, snapshots, achievements and study-planning tools.
  • Demo-safe authentication and disposable reviewer login flows.
  • Free / Premium feature gating backed by real application state.
  • Mock checkout, plan switching and downgrade behaviour with no real payment processor involved.
  • AI-style mentor and reporting experiences implemented as deterministic local demo behaviour rather than requiring a paid external service.
  • Settings persistence, import/export and backup/restore flows.
  • Backend regression tests plus Playwright browser coverage for key reviewer journeys.

Engineering decisions

  • Demo boundaries are explicit: billing and AI-style functionality are intentionally mock-only so the portfolio never implies that a production SaaS is running.
  • Progressive complexity: core academic data remains understandable even as forecasting, planning and premium-style features are layered on top.
  • Verification from the user’s point of view: Playwright checks important browser journeys in addition to backend tests.
  • Recoverability matters: settings and data-management flows are treated as product features rather than afterthoughts.

Verification

The final portfolio audit passed 115/115 Django backend tests and 130/130 Playwright browser and visual tests, including desktop/mobile and dark/light coverage. A separate live-deployment smoke test also passed against the public Render demo, verifying demo sign-in, core pages, Free → Premium → Free mock billing, Premium-only report access and restored gating after downgrade.

What this demonstrates

This is my strongest full-stack portfolio project because it shows more than framework knowledge. It demonstrates how I structure a multi-feature product, improve consistency across screens, think about failure states, test user journeys and keep the application understandable as scope grows.
