PredictMyGrade

A Django product mockup exploring how students could track academic progress, forecast outcomes, plan study activity and interact with premium-style product journeys in one coherent interface.

Representative interface preview

The product

PredictMyGrade is deliberately positioned as a portfolio/demo build rather than a production education service. It demonstrates end-to-end product thinking: authentication, persisted academic data, dashboards, forecasting-style metrics, study planning, AI-assisted demo flows and simulated premium journeys.

What I implemented

  • Weighted academic dashboards and progress summaries.
  • University and GCSE-style module workflows.
  • Goals, deadlines, snapshots, study planning and calendar export.
  • AI-assisted reports, mentor-style chat and what-if forecasting demos with fallback behaviour.
  • Mock premium checkout and subscription management flows.
  • Admin tooling for analytics, billing visibility, system health and user management.
  • Backend tests plus Playwright browser smoke tests for key user journeys.

Architecture

Browser ↓ Django templates + views ↓ Models / forms / services / tasks ↓ SQLite locally → PostgreSQL-ready ↓ Optional integrations + Playwright E2E tests

Engineering focus

The interesting part of this project is not one algorithm; it is the coordination of many product concerns into a consistent application. I worked across UX consistency, Django architecture, persistence, feature gating, fallback behaviour, testing and demo-safe positioning.
