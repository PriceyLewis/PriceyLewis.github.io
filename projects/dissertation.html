Academic Performance Calculator

A Java Swing desktop application for managing university modules, calculating weighted performance, visualising grades, persisting data and generating a lightweight forecasting summary.

Representative interface preview

The problem

Academic results are often scattered across modules and assessments. I built a desktop tool that consolidates module data into a single view and turns it into a clearer performance picture.

What I implemented

  • Java Swing dashboard with a guided demo login.
  • Validated module management and live weighted-grade updates.
  • Bar and pie chart visualisation.
  • CSV import and export.
  • Microsoft Access persistence through UCanAccess.
  • Undo-style table restoration and sample data for easy demonstration.
  • Forecasting summary based on current module data.

Architecture

Swing UI ↓ MainWindow / event handling ↓ Module DAO + prediction helper ↓ UCanAccess JDBC ↓ Microsoft Access database

What it demonstrates

The project brings together desktop UI development, event-driven programming, validation, local persistence, file handling, data visualisation and forecasting in a single employer-friendly demo.
