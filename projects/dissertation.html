Academic Performance Calculator

My final-year dissertation: a Java Swing application for module management, weighted performance tracking, visualisation, Microsoft Access persistence and prediction-style academic guidance.

Representative dissertation interface preview

The problem

University performance can be difficult to understand when grades, module credits, attendance and study information are spread across different places. I built a desktop application that consolidates this information and turns it into a clearer view of current performance and likely classification.

This project was my opportunity to combine object-oriented programming, persistence, visualisation and prediction logic in one complete piece of software rather than separate coursework exercises.

What I built

  • Java Swing interface for adding, editing, deleting and clearing module records.
  • Undo-style restoration for accidental table changes.
  • Weighted performance calculations using grade and credit information.
  • CSV import and export plus database backup and load workflows.
  • Microsoft Access persistence through UCanAccess.
  • JFreeChart visualisations for performance trends and summaries.
  • Prediction-style classification output based on current academic data.
  • Scorecard and advice views to turn raw results into more useful feedback.

Engineering decisions

  • Desktop-first scope: Swing and local persistence matched the dissertation goal and kept the project self-contained.
  • Data validation: module inputs needed to remain internally consistent before being used in weighted calculations or predictions.
  • Recoverability: import/export, backup and undo-style behaviour make the tool easier to demonstrate and safer to experiment with.
  • Explainable outputs: charts and scorecards make academic performance easier to interpret than a single classification label.

Architecture

Java Swing UI ↓ Event handling + validation ↓ Module management + prediction helper ↓ UCanAccess / JDBC ↓ Microsoft Access database ↓ Charts + scorecard feedback

What this demonstrates

The dissertation demonstrates end-to-end ownership of a larger Java application: designing the interface, modelling data, connecting a database, handling files, calculating outcomes, visualising results and delivering a complete working system as an assessed final-year project.
