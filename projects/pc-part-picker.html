PC Part Picker Tool

A Java Swing desktop application for browsing PC components, comparing store listings, using a deterministic local assistant and building a basket from a bundled Microsoft Access database.

Representative interface preview

The product

The application combines component browsing, search and filtering, basket functionality, store reviews, user history and local recommendation logic around a bundled parts database. The portfolio version is self-contained and does not require a cloud AI service, hosted backend or paid API.

My contribution

This began as team coursework. My main contribution included Java Swing application work, database-backed flows and the assistant integration. The portfolio repository explicitly keeps that team context rather than presenting every original feature as solely authored by me.

What the demo includes

  • Account sign-up and demo login flows.
  • In-stock part browsing across stores.
  • Keyword, brand and price filtering.
  • A deterministic local rule-based assistant for component and store questions.
  • Basket management with running totals.
  • Store reviews and recent search history.
  • Database query/update handling through UCanAccess / Jackcess.

Engineering focus

  • Database-backed UI: multiple Swing flows share state stored in Microsoft Access.
  • Deterministic assistant behaviour: recommendations are generated locally from database contents rather than depending on an external AI service.
  • Safer demo actions: mutating assistant-style actions require confirmation.
  • Portable demo setup: the app searches for its database and assets rather than relying on one developer-machine path.

Verification

GitHub Actions compiles the Java source against the bundled dependencies on every push and pull request. The repository also includes Windows and shell launchers so the documented demo path matches files that actually exist.

Architecture

What this demonstrates

This additional project demonstrates team software development, Java desktop UI work, database access, search and filtering logic, user-facing state and the ability to turn a coursework system into a clearer self-contained portfolio demo.
