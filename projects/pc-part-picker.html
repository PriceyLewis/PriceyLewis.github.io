PC Part Picker Tool

A Java Swing desktop application for browsing components, filtering store listings, receiving local recommendations and building a basket from a bundled Microsoft Access database.

Representative interface preview

The product

The application combines search, filtering, basket functionality, reviews, user history and recommendation logic around a local parts database. It was built as a self-contained demo that does not require an external API or hosted backend.

What I implemented

  • Account sign-up and demo login flows.
  • In-stock part browsing across stores.
  • Keyword, brand and price filtering.
  • Local recommendation suggestions based on bundled data.
  • Basket management with running totals.
  • Store reviews and recent search history.
  • Database query/update handling through UCanAccess / Jackcess.

Architecture

Java Swing UI ↓ Main application flow ↙ ↓ ↘ Search Basket Reviews ↓ DatabaseAccess ↓ Microsoft Access

Engineering focus

This project demonstrates data-driven desktop UI design, database access, search/filter logic and user-facing state across multiple connected flows.
