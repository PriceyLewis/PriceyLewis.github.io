Guardian Antivirus

A Linux desktop security project built around Python, Qt and ClamAV, combining malware scanning, real-time file monitoring, quarantine workflows and application-level scan history.

Representative interface preview

The product

Guardian explores how a Linux-focused security utility can wrap mature scanning capabilities in a more approachable desktop experience. The project focuses on orchestration, state, UI feedback and safe file-handling workflows.

Core capabilities

  • Quick, full and custom scan flows.
  • ClamAV-backed malware scanning.
  • Real-time filesystem monitoring.
  • Quarantine management for detected files.
  • SQLite-backed scan records and application state.
  • Desktop tray integration and protection-status UI.
  • Settings and user-facing protection controls.

Architecture

PySide6 / Qt UI ↓ Scan Manager + Protection State ↙ ↓ ↘ ClamAV Watcher Quarantine ↓ SQLite

Engineering focus

The project is useful as a portfolio piece because it goes beyond CRUD-style application development. It combines operating-system integration, long-running background behaviour, external security tooling and a desktop interface that needs to communicate protection state clearly.
