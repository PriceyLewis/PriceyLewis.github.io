Student Toolkit OS

A React Native / Expo product concept that brings academic planning, habits, fitness, career progress and side-income goals into one local-first mobile experience.

Representative interface preview

The product

The goal was to explore a broad, connected mobile product without relying on a backend. The app persists user state on-device and uses a shared application architecture to coordinate dashboards, planners, habits, reminders and analytics.

What I implemented

  • Onboarding and profile setup.
  • Dashboard scoring across academic, fitness, hustle and career categories.
  • Revision, gym, side-income and CV planning screens.
  • Habit completion history, difficulty weighting and streak logic.
  • Weekly review and analytics views.
  • AsyncStorage persistence, local backup/restore and notification flows.
  • Export and sharing support for selected planning workflows.

Architecture

Expo Router screens ↓ React Context state ↓ Feature modules / utilities ↓ AsyncStorage persistence ↓ Notifications + local backup / restore

Engineering focus

This project demonstrates multi-screen UX, local-first state management and product cohesion. A major challenge was making different planning tools feel like parts of the same system instead of separate mini-apps.
